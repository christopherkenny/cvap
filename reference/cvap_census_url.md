# Get Zip File URL for CVAP Special Tabulation Data

Get Zip File URL for CVAP Special Tabulation Data

## Usage

``` r
cvap_census_url(year = 2023)
```

## Arguments

- year:

  numeric. Year for the data in 2009 to 2023.

## Value

string

## Examples

``` r
cvap_census_url()
#> https://www2.census.gov/programs-surveys/decennial/rdo/datasets/2023/2023-cvap/CVAP_2019-2023_ACS_csv_files.zip
```
